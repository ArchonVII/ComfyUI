## Example

The six-node arch-pt chain, as one text field:

```
__archpt/flux/identity/*__, __archpt/flux/pose/base_pose__,
__archpt/flux/clothing/outfit_type__, __archpt/flux/environment/location_type__,
__archpt/flux/camera/focal_length__, __archpt/flux/lighting/primary_direction__
```

Hold a value steady across positive, negative and style fields by
assigning it once and reusing the variable:

```
__archpt/flux/identity/hair_color^hair__ ... later ... __^hair__
```
